# Event Website

## Project Description

This is a responsive event website created as part of the Milestone 1 Project.
The website provides information about the event, schedule, speakers/performers,
ticket options, venue and registration.

## Pages

- Home
- Schedule / Lineup
- Speakers / Performers / Highlights
- Register

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Git
- GitHub

## Features

- Responsive design
- Event schedule
- Speakers / performers section
- Ticket pricing
- Registration form
- Venue / location information
- Mobile-friendly layout
- Hover and focus effects
